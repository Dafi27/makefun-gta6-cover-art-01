Palm Heat Cover Lab — an offline web app that turns any photo and a caption into GTA 6-style cover art: a multi-panel poster with bold Anton lettering, a Pacifico subtitle and a Vice City sunset or neon colour grade, exported as a PNG in 1080×1080, 1080×1350 and 1920×1080. Upload your own photos or use the three procedural sample scenes, crop and position each panel, pick from four layouts and five grades, and export all three post sizes in one step. Everything runs on your machine — no uploads, no servers, no watermark.

## Run it

```sh
npx --yes serve app
```

Then open http://localhost:3000 in a desktop browser.
